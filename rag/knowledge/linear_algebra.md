# 考研数学一线性代数核心知识点与解题技巧

## 一、行列式
### 核心知识点
1. **定义与性质**
   - 逆序数定义：n阶行列式为n!项的代数和
   - 七大性质：转置不变、两行互换变号、数乘、拆分、倍加不变等
   - 特殊行列式：对角、三角、范德蒙、分块行列式

2. **计算方法**
   - 化三角形法（最常用）
   - 递推法与数学归纳法
   - 行列式展开定理（按行/列展开）
   - 加边法（升阶法）
   - 利用特征值求行列式

### 做题技巧
- **先观察后计算**：先看是否有特殊结构（如各行元素和为常数、范德蒙形式）
- **符号处理要仔细**：展开时注意(-1)^(i+j)的符号
- **抽象行列式**：常利用矩阵运算性质转化为已知行列式
- **|A+B|型**：一般不能直接拆分，需通过相似、特征值等间接求解

## 二、矩阵
### 核心知识点
1. **矩阵运算**
   - 乘法不满足交换律、消去律
   - 伴随矩阵：AA* = A*A = |A|E
   - 逆矩阵：A可逆⇔|A|≠0⇔r(A)=n⇔A的特征值全非零

2. **矩阵的秩**
   - 定义：最高阶非零子式的阶数
   - 重要公式：
     - r(A) = r(A^T) = r(A^TA) = r(AA^T)
     - r(A+B) ≤ r(A) + r(B)
     - r(AB) ≤ min{r(A), r(B)}
     - 若A可逆，则r(AB)=r(B)

3. **分块矩阵**
   - 分块乘法原则：前行分块列数=后列分块行数
   - 分块对角矩阵的逆和幂

### 做题技巧
- **求逆矩阵**：
  - 数字矩阵：用伴随矩阵法(A⁻¹ = A*/|A|)或初等变换法
  - 抽象矩阵：用定义AA⁻¹=E或利用已知公式（如(A+E)⁻¹）
- **证明秩的关系**：常用方法：
  1. 利用秩的定义（找最大无关组）
  2. 利用齐次方程组AX=0的基础解系
  3. 利用向量组的线性表示
- **分块矩阵技巧**：处理高阶矩阵时，按特殊结构分块可简化计算

## 三、向量组与线性方程组
### 核心知识点
1. **向量组的线性相关性**
   - 定义：存在不全为零的k₁,...,kₛ使k₁α₁+...+kₛαₛ=0
   - 判定方法：
     - 向量个数>维数必相关
     - 用秩判断：r(α₁,...,αₛ)<s⇒相关
     - 含零向量必相关

2. **极大无关组与秩**
   - 求法：将向量组按列排成矩阵，初等行变换化阶梯形
   - 向量组的秩=矩阵的秩

3. **线性方程组**
   - 齐次AX=0：
     - 有非零解⇔r(A)<n
     - 基础解系含n-r(A)个解向量
   - 非齐次AX=b：
     - 有解⇔r(A)=r(A|b)
     - 通解=特解+齐次通解

### 做题技巧
- **相关性的证明题**：
  - 用定义法（设系数，推导矛盾）
  - 用秩的公式
  - 反证法
- **求基础解系**：必须确保解向量线性无关
- **含参数的方程组**：对参数分类讨论，一般按秩是否满进行分类
- **公共解与同解**：
  - 公共解：联立方程组或利用解的结构
  - 同解：证明互相包含，常用秩的等式r(A)=r(B)=r([A;B])

## 四、特征值与特征向量
### 核心知识点
1. **基本概念**
   - 定义：Aα=λα（α≠0）
   - 求法：解|λE-A|=0得特征值，解(λE-A)X=0得特征向量
   - 性质：
     - ∑λᵢ = tr(A)，∏λᵢ = |A|
     - 不同特征值对应的特征向量线性无关

2. **相似对角化**
   - A可对角化⇔A有n个线性无关的特征向量
     ⇔每个k重特征值有k个线性无关的特征向量
   - 应用：求Aⁿ = PΛⁿP⁻¹

3. **实对称矩阵**
   - 特征值都是实数，不同特征值对应的特征向量正交
   - 必可正交相似对角化：A=QΛQ^T（Q为正交矩阵）

### 做题技巧
- **快速求特征值**：
  - 观察迹和行列式
  - 对于2阶、3阶矩阵可直接计算
  - 有特殊结构（如各行和为常数）时，必有特征向量(1,1,...,1)^T
- **相似证明题**：
  - 证有相同特征多项式（必要不充分）
  - 证都可对角化且特征值相同
  - 用相似传递性
- **实对称矩阵的正交对角化步骤**：
  1. 求特征值
  2. 求特征向量
  3. 重根的特征向量需施密特正交化
  4. 单位化得正交矩阵Q

## 五、二次型
### 核心知识点
1. **基本概念**
   - 二次型f=x^TAx（A为实对称矩阵）
   - 标准形：只含平方项
   - 规范形：系数为±1或0

2. **合同变换**
   - A与B合同⇔存在可逆C使C^TAC=B
   - 惯性定理：正负惯性指数在合同变换下不变

3. **正定二次型**
   - 定义：∀x≠0，f=x^TAx>0
   - 判定：
     - 顺序主子式全>0
     - 特征值全>0
     - 正惯性指数p=n

### 做题技巧
- **化二次型为标准形**：
  - 配方法（通用）
  - 正交变换法（得标准形且保持几何形状）
- **正定性的证明**：
  - 用定义（需技巧）
  - 用顺序主子式（最常用）
  - 证与已知正定矩阵合同
- **已知标准形反求参数**：利用惯性指数或特征值的性质

## 六、综合解题策略
### 1. 选择题快速解法
- **特殊值法**：取简单矩阵验证选项
- **排除法**：利用反例排除错误选项
- **几何直观**：2维、3维向量问题可画图辅助

### 2. 证明题常用思路
- **“⇔”型命题**：充分必要性分开证
- **“存在性”命题**：构造法或反证法
- **秩的不等式**：利用向量组表示或方程组解的结构

### 3. 计算题注意事项
- **特征多项式**：展开时注意符号，建议用|λE-A|
- **初等变换**：仅用行变换时，矩阵关系要标注清楚
- **正交化**：施密特过程要逐步计算，避免连锁错误

### 4. 时间分配建议
- 小题（选择填空）：3-5分钟/题
- 计算题：10-15分钟/题
- 证明题：8-12分钟/题

---

## 七、易错点提醒
1. 矩阵乘法不满足交换律，消去律
2. 特征向量必须是非零向量
3. 相似⇔相同特征值（但反之不成立，除非可对角化）
4. 合同⇔相同正负惯性指数（不要求特征值相同）
5. r(A)=r(A^TA)仅对实矩阵成立
6. 二次型矩阵必须是实对称矩阵，讨论前先对称化
