# 考研数学一高等数学部分知识点与做题技巧总结

## 一、核心知识点体系

### 1. 函数、极限与连续
*   **函数**
    *   基本初等函数、初等函数的性质与图形。
    *   函数的四大特性：有界性、单调性、奇偶性、周期性。
    *   复合函数与反函数。
*   **极限**
    *   **定义与性质**：数列极限、函数极限（`x→∞`， `x→x0`）的`ε-δ`/`ε-N`语言理解。
    *   **计算方法**：
        1.  利用基本极限（如 `lim(x→0) sinx/x = 1`）。
        2.  等价无穷小替换（乘除可用，加减慎用）。
        3.  洛必达法则（验证 `0/0` 或 `∞/∞` 型）。
        4.  泰勒公式展开（求极限最有力的工具，需熟记常见展开式至 `x^3` 或 `x^4` 项）。
        5.  夹逼准则。
        6.  单调有界准则（常用于数列极限）。
*   **连续**
    *   连续的定义与间断点类型（第一类、第二类）。
    *   闭区间上连续函数的性质：有界性、最值定理、介值定理、零点定理。

### 2. 一元函数微分学
*   **导数与微分**
    *   导数定义（增量极限）与几何意义（切线斜率）。
    *   微分的定义与几何意义（切线纵坐标增量）。
    *   计算：基本求导公式、四则运算、复合函数求导（链式法则）、隐函数求导、参数方程求导、反函数求导、对数求导法、高阶导数。
*   **微分中值定理**
    *   **费马引理**、**罗尔定理**、**拉格朗日中值定理**、**柯西中值定理**。理解其几何意义与相互关系。
    *   **泰勒公式**（拉格朗日余项、皮亚诺余项）：连接函数与导数信息的桥梁，用于近似、证明和极限计算。
*   **导数的应用**
    *   单调性与极值：一阶导数判单调，驻点/不可导点处可能取极值，用第一或第二充分条件判断。
    *   凹凸性与拐点：二阶导数判凹凸，拐点处二阶导变号或不存在。
    *   渐近线：水平、垂直、斜渐近线的求法。
    *   最值问题：闭区间上比较端点、驻点、不可导点的函数值。
    *   方程根的存在性与个数：常结合零点定理和单调性讨论。

### 3. 一元函数积分学
*   **不定积分**
    *   原函数与不定积分的概念。
    *   **核心计算方法**：
        1.  基本积分公式。
        2.  第一类换元法（凑微分）。
        3.  第二类换元法（三角代换、根式代换、倒代换等）。
        4.  分部积分法（`∫u dv = uv - ∫v du`， 优先顺序：反三角/对数函数 > 代数函数 > 三角/指数函数）。
*   **定积分**
    *   定义（黎曼和极限）与几何意义（曲边梯形面积）。
    *   性质：线性性、区间可加性、比较定理、积分中值定理。
    *   **计算方法**：
        1.  牛顿-莱布尼茨公式（连接微分与积分）。
        2.  换元积分法（注意换元必换限）。
        3.  分部积分法。
        4.  利用奇偶性、周期性简化计算。
    *   **变限积分函数**：其求导公式 `[∫(a→φ(x)) f(t) dt]' = f(φ(x)) * φ'(x)` 是重点。
    *   **广义积分（反常积分）**：无穷区间、无界函数的积分。核心是转化为极限问题，并用比较判别法或极限判别法判断敛散性。
*   **定积分的应用**
    *   几何应用：平面图形面积、旋转体体积、平面曲线弧长、侧面积。
    *   物理应用：变力做功、液体静压力、质心/形心（数一重点）。

### 4. 向量代数与空间解析几何（数一专项）
*   向量运算：数量积、向量积、混合积的运算与几何意义。
*   平面与直线方程：点法式、一般式、对称式、参数式及其相互关系（平行、垂直、夹角、距离）。
*   曲面与曲线：常见二次曲面（柱面、旋转曲面、椭球面、抛物面、双曲面）的方程与图形。空间曲线的投影。

### 5. 多元函数微分学
*   **基本概念**
    *   二元函数极限、连续的定义。
    *   偏导数、全微分的定义与计算。
    *   连续、偏导存在、可微、偏导连续之间的关系（重要）。
*   **计算**
    *   复合函数求导（链式法则）：画出变量关系图是关键。
    *   隐函数（一个方程或方程组）求导。
*   **应用**
    *   几何应用：空间曲线的切线与法平面，曲面的切平面与法线。
    *   极值与最值：
        1.  **无条件极值**：利用 `AC-B^2` 判别法。
        2.  **条件极值**：拉格朗日乘数法，构造辅助函数 `F = f + λφ`。

### 6. 多元函数积分学（数一重点与难点）
*   **二重积分**
    *   性质与计算：直角坐标下交换积分次序，极坐标变换（`x=rcosθ， y=rsinθ， dxdy=rdrdθ`）。
*   **三重积分**
    *   计算：直角坐标（投影法/截面法）、柱坐标（`x=rcosθ， y=rsinθ， z=z， dv=rdrdθdz`）、球坐标（`x=ρsinφcosθ， y=ρsinφsinθ， z=ρcosφ， dv=ρ²sinφ dρdφdθ`）。
*   **曲线积分**
    *   **第一类（对弧长）**：与方向无关，化为定积分计算。
    *   **第二类（对坐标）**：与方向有关。**格林公式**（平面闭曲线）是核心，沟通了曲线积分与二重积分。注意积分路径是否为闭、单连通区域、`P，Q`是否具有一阶连续偏导等条件。
*   **曲面积分**
    *   **第一类（对面积）**：与侧无关，投影到坐标面计算。
    *   **第二类（对坐标）**：与侧有关。**高斯公式**（空间闭曲面）是核心，沟通了曲面积分与三重积分。**斯托克斯公式**（空间非闭曲线）沟通了曲线积分与曲面积分。
*   **场论初步**
    *   散度、旋度的计算。
    *   保守场（梯度场）的判定：旋度为0，或曲线积分与路径无关。

### 7. 无穷级数（数一重点）
*   **常数项级数**
    *   收敛与发散的定义。
    *   **正项级数审敛法**：比较判别法、比值判别法（达朗贝尔）、根值判别法（柯西）、积分判别法。
    *   **任意项级数**：绝对收敛与条件收敛。莱布尼茨判别法用于交错级数。
*   **幂级数**
    *   收敛半径、收敛区间、收敛域的求法（`R = lim |a_n/a_{n+1}|`）。
    *   和函数的求法：逐项求导、逐项积分、利用常见展开式。
    *   函数展开成幂级数：直接法（求各阶导数），间接法（利用 `e^x， sinx， cosx， ln(1+x)， (1+x)^a` 的展开式进行变形）。
*   **傅里叶级数（数一专项）**
    *   狄利克雷收敛定理。
    *   将函数展开为正弦/余弦级数。

### 8. 常微分方程
*   **一阶方程**
    *   可分离变量、齐次、一阶线性（公式法或常数变易法）、伯努利方程。
*   **高阶方程**
    *   可降阶的高阶方程：`y'' = f(x， y')` 型， `y'' = f(y， y')` 型。
    *   **高阶线性微分方程**：
        1.  解的结构（齐次通解+非齐次特解，叠加原理）。
        2.  常系数齐次线性方程：特征方程法。
        3.  常系数非齐次线性方程：待定系数法（根据自由项 `f(x)` 的类型设特解形式）。
*   **微分方程的应用**：几何问题、物理问题。

## 二、核心做题技巧与策略

### 1. 审题与思路构建
*   **识别题型**：看到题目，快速归类（求极限、证明不等式、计算积分、判断级数敛散性等），调用对应的知识模块。
*   **挖掘隐含条件**：注意定义域、奇偶性、周期性、对称性等，能极大简化计算。
*   **逆向思维**：从结论出发，分析需要什么条件，反推解题步骤。

### 2. 计算技巧
*   **先化简，后计算**：计算前先对表达式进行代数、三角恒等变形，化简积分、极限形式。
*   **对称性优先**：在重积分、曲线曲面积分中，优先考察积分区域和被积函数的对称性（奇偶性），可化繁为简甚至直接得出结果。
*   **选择最优工具**：
    *   求极限：泰勒展开 > 等价无穷小 > 洛必达法则。
    *   求积分：先看能否凑微分，再考虑换元，最后分部。对于特定形式（如 `∫ e^x sinx dx`）的分部积分，可用“循环法”或“表格法”。
*   **勤画草图**：对于几何、物理应用题，以及多重积分、线面积分的题目，画出示意图是理清区域、边界、方向的关键。

### 3. 证明题策略
*   **中值定理证明**：
    *   涉及函数值差 `f(b)-f(a)`：考虑拉格朗日中值定理。
    *   涉及两个函数值差：考虑柯西中值定理。
    *   涉及导数零点或方程根：考虑罗尔定理（关键是构造辅助函数）。构造辅助函数常用方法：原函数法、微分方程法、常数变易法。
*   **不等式证明**：
    *   单调性法：移项构造函数，利用导数判断单调性。
    *   中值定理法：将函数值差与导数联系起来。
    *   凹凸性法：利用函数的凹凸性定义。
    *   最值法：证明函数最大值≤0或最小值≥0。
*   **存在性证明**：常用介值定理、零点定理、罗尔定理。

### 4. 常见易错点与注意事项
*   **概念混淆**：可导与连续、可微与偏导连续、条件收敛与绝对收敛、函数项级数与数项级数收敛性。
*   **计算失误**：
    *   求导/积分公式记错。
    *   换元积分未回代或定积分未换限。
    *   级数求和未注明收敛域。
    *   线面积分中方向（侧）判断错误。
*   **审题不清**：忽略“一阶连续偏导”等条件而误用格林/高斯公式；忽略广义积分的瑕点。

### 5. 复习与应试建议
*   **知识网络化**：不要孤立记忆公式定理，要建立章节间联系（如微分中值定理与积分中值定理、格林/高斯/斯托克斯公式的统一性）。
*   **真题为王**：反复研究历年真题，总结高频考点、常见题型和命题风格。
*   **错题深究**：建立错题本，分析错误原因是概念不清、方法不会还是计算粗心，定期回顾。
*   **模拟实战**：定期限时完成套题，训练答题节奏和应变能力。合理分配时间，选择填空要快准，解答题步骤清晰。
